# Issue #2297: Add ExcludeFromCodeCoverage attribute to generated code.
Opened by SergeyBarskiyTyler, 2026-09-11. State: open.

## Is your feature request related to a problem? Please describe.
MessagePack generated code is not decorated with ExcludeFromCodeCoverage
attribute. Writing good coverage for generated MessagePack code is very hard,
which may skew coverage numbers, especially on large projects with a lot of
generated code.

## Describe the solution you'd like
I would like all generated code to be decorated with ExcludeFromCodeCoverage
attribute. I do not feel like a setting is needed, but setting would be fine to
have too.

## Describe alternatives you've considered
There are no alternatives. Good coverage of generated code is close to
impossible because it covers many edge cases.
